# Beginners-Guide-to-Linux

This repository contains the presentation materials for the Bash Basics workshop conducted on November 11, 2026.

# Workshop Overview

The session was hosted by Richard Hammingh, the IEEE CS workshop chair.

In this workshop we went over what bash is, some uses of bash, and how to use bash. We helped attendees understand behaviors, commands, and syntax behind bash. We went over a simple script that was made before hand to clean and sort out the downloads folder.
